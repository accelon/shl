# 注疏 crosswalk 筆記（`xref.tsv` v1）

> 2026-11-05。實作 `src/build-xref.ts`；資料 `data/xref.tsv`；摘要 `data/xref-summary.json`。
> 目標：每一家注本的段落 → 宋本條（→ 軌號 range）。只存對映，不复制原文。

## 1. 方法

```text
jicheng HTML / jc.adb XML
  → parseBook()／parseJcXml()：標題層 + 段落（抽掉雙行小字／校注）
  → normHan()：只留漢字，統一常見異體
  → 4-gram 倒排索引
  → 每條找候選段落（coverage >= 門檻）
  → 單調本用加權 DP 選一致路徑；重編本取全域最佳
  → 連續條文共用同一段落時合併
```

- **覆蓋率**：clause 的 4-gram 有多少出現在該段落；1.00 表示逐字相同（去標點）。
- **單調本**：成無己、康平、淺註、輯義、集成、張卿子、彙註、補亡論、曹氏。
- **重編本**：條辨、尚論、來蘇集、貫珠、溯源、懸解、綱目、類方、活人書、桂林、金匱玉函。
- **source 範圍**：anchor 到下一條 anchor 之前；最多 13 段；遇到別條候選或「（十一）」新條號就停。
- **合併**：兩條共用同一段落時合成一列，`relation=n:1`。

## 3. 欄位

| 欄 | 說明 |
|---|---|
| `work_id` | 注本 ID（對應 `witnesses.tsv`） |
| `source_start` / `source_end` | 該書段落 id（有 `<p id>` 用 id，否則 `p<idx>`） |
| `source_label` | 標題路徑 + 段落 id |
| `track_start` / `track_end` | 對到的宋本軌號 range |
| `relation` | `1:1`、`1:n`、`n:1`、`n:m`、`gap` |
| `confidence` | A／B／C，由 coverage 分級 |
| `coverage` | 4-gram 覆蓋率 |
| `method` | `best-monotonic`／`best-global`／`none` |
| `note` | 體例備註 |

### 3.1 `align.tsv`（別本）

`src/build-align.ts` 由 xref 抽 KP／GL／YH，共 1,132 列：

- `track_a`：宋本該條第一句軌號。
- `track_b`：別本 realization id，如 `KP.p69`、`GL.6.13`。
- `gap` 列 `track_b` 空，明示缺此條。
- `src/build-witness-tracks.ts` 另出 `data/tracks-witness.tsv`（1,471 軌），
  `track_id = <work>.<source_start>`，讓 `track_b` 兩端都可解析。

### 3.2 錨點審計

`src/audit-xref.ts` 檢查非 gap 列的 `source_start` 是否真的含該條 8 字片段：

- 20 家全文注本：95.6%–99.7% 命中；A 級幾乎 100%（HZ 254/255）。
- 早期節錄：MJ 90%、QY 92.6%、WT 87.3%、SHF 77.3%；低是意引，不是硬錯誤。
- 結果 `data/xref-audit.json`。

### 3.3 `xref-sentence.tsv`（句級 pilot）

`src/build-xref-sentence.ts`：對 8 家、每個條級 xref row，把注疏 span 切句，
每句先找 4-gram 最高的；≥0.45 且單調者記 `quote`，其餘依前後錨點內插（`interp`），無錨點則按比例散開（`spread`）。

| 項目 | 量 |
|---|---:|
| 列數 | 78,283 |
| quote | 11,018 |
| interp／spread／lead／tail | 67,265 |

- `quote` 是高信度句對句；`interp` 是依前後錨點推的句，較弱。
- 用單調 greedy 錨點＋前後內插；沒有全域 LIS，短句仍可能錯掛。
- 這版已用於 `/incubator/shl-sentence.html`（pilot），不是定本。

## 4. 已知問題

1. **成無己分合**：第 6 條拆成兩段，anchor 落在後半，`1:n`、coverage 0.76（B）；要看注文是否完整。
2. **重編本路徑**：條辨、尚論、貫珠按法重排，`best-global` 可能指到後面的重複引文；C 級先校。
3. **桂林異文**：字句差異大，4-gram 覆蓋率較低；C 級不宜當定論。
4. **短條易誤配**：<20 字的條 4-gram 太少；已用門檻擋一部分，仍要抽查。
5. **方證範圍**：`source_end` 會把方名、藥味、煎服法包進來；若只取注文，要另切 formula。
6. **輯義／類方／活人書偏低**：體例本來就不是逐條，應改做方／證索引。
