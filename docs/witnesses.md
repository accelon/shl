# 傷寒論重要週邊文獻清單（v1）

> 2026-11-05。範圍：`shl` 階段一（漢文本文＋注疏群）。
> 機器可讀：`data/witnesses.tsv`（47 筆：34 筆已下載＝33 笈成 HTML＋1 四庫 skqs、3 筆 jc.adb 抽出、7 筆待補、3 筆 external）；對位結果：`data/xref.tsv`。

## 0. 「週邊」的兩層意思

| 層 | 指什麼 | 在本專案的位置 |
|---|---|---|
| **書內周邊**（paratext） | 398 條以外的篇：序、辨脈、平脈、傷寒例、痙濕暍、可與不可、卷十方論 | 已建軌，`X0001`–`X0223` |
| **書外周邊**（witnesses） | 別本、早期傳本、注本、類證／通論、參照書 | `data/witnesses.tsv`、`data/xref.tsv` |

兩層都要，因為「一條」的邊界不是靠本文自己決定的：要有別的傳本與注本，才知道哪裡是共識切點。

## 1. 版本譜系（底本鏈）

```text
張仲景《傷寒雜病論》（約 200）
   │
   ├─ 王叔和 撰次 → 《脈經》卷七–九（約 280）        ← 最早可考編次
   │        │
   │        ├─ 孫思邈《千金翼方》卷九–十（682）      ← 唐初傳本
   │        ├─ 王燾《外臺秘要》卷一–二（752）        ← 唐中期引本
   │        └─ 高繼沖 進上本（開寶 968–975）         ← 佚
   │                 │
   │                 └─ 《太平聖惠方》卷八（992）     ← 淳化本
   │
   └─ 林億等 校正（1066）→ 宋本系統（趙開美 1599 翻刻）
            │
            ├─ 成無己《註解傷寒論》（1144）          ← 第一家全文注
            ├─ 《金匱玉函經》（別本）
            ├─ 日本 康平本（1060 寫本）、康治本（1143 寫本）
            └─ 桂林古本（1930s 傳出，真偽有爭議）
```

要點：

- 林億序稱「總二十二篇，證外合三百九十七法，除重複定有一百一十二方」。今通行「398 條」是後人（多說為劉渡舟等教材系統）所編，與宋人「397 法」不是同一個計數。
- 本專案用 **398 條號** 作 base，是因為它是現代最通行的引用號；但**條界**要由多本共識決定，不由 398 條號決定。
- 中醫笈成《傷寒論（宋本）》的底本是《四部叢刊初編·註解傷寒論》（成無己注本系統），不是趙開美獨立宋本。字句仍要與真宋本對校；條號可先用。

## 8. 授權與出處
