# 術語表 pilot（`glossary.tsv`）

> 2026-11-05。資料 `data/glossary.tsv`；31 條核心術語。
> 不是詞典全文，只是一組「讀傷寒論一定會遇到」的術語與最短定義，供閱讀器右欄與搜尋使用。

## 1. 欄位

| 欄 | 說明 |
|---|---|
| `term` | 術語 |
| `category` | 六經／病名／證候／傳變／篇名 |
| `gloss` | 最短定義，附關鍵原文 |
| `first_track` | 首次出現的軌號（可點回主文） |
| `note` | 與相鄰概念的區別 |

## 2. 選詞原則

- 只收**反覆出現、且定義會影響理解**的詞；不作人名、書名、方名詞典。
- 定義尽量用《傷寒論》原文，不引入後世過度詮釋；有爭議者在 `note` 標出。
- 六經條目只給提綱，不展開氣化、標本中氣等學說。
- 篇名條目（傷寒例、辨脈、平脈）標明「非 398 條本文」，避免與經文混淆。

## 3. 限制

- 這是**pilot**，31 條；方名、藥名、穴位尚未收。
- 定義是編者語，不是唯一解；不同注家對「厥」「蓄血」「痞」的範圍有出入。
- `first_track` 只記首次出現，不記全部出現；要做全文索引時另建 `term_occurrences.tsv`。
- 未做簡繁與異體匹配；「脈」與「脉」、「證」與「证」暫不互通。

## 4. 下一步

1. 與 `hdnj` 的內經術語表對齊（同一詞在不同書的定義可能不同）。
2. 加方名、藥名、穴名三類。
3. 為每條術語加 2–3 個注家定義（成無己、柯琴、尤怡），做「一詞多解」。
4. 產生 `term_occurrences.tsv`（term × track），供搜尋與高亮。
