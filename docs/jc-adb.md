# 用 `jc.adb` 掃中醫笈成

> 2026-11-05。工具：`D:\2026\adb-converter\ts`（abx，Bun/TypeScript）。
> 目的：不再逐本抓 HTML，直接從 Accelon3 資料庫抽書、對目錄、補缺本。

## 1. 為什麼改用 ADB

- `d:\accelon3\jc.adb` 是 337.5 MiB 的 Accelon3 資料庫，**1,359 本書、129,740,847 字**。
- 一次匯出 XML 約 **2.7 秒**（14 執行緒），比逐本 HTTP 抓取快，也不受 jicheng 429 影響。
- 匯出的 XML 保留 `<書名>`、`<作者>`、`<章>`、`<節>`、`<項>`、`<目>`、`<條>` 與 `◇` 段落標記，
  比 HTML 更接近原始結構。

## 2. 指令

```bash
cd D:\2026\adb-converter\ts

# 1) 全庫 → XML（388 MB，一個 jc.xml）
bun run src/cli.ts export D:\accelon3\jc.adb -o D:\2026\shl\out\jc-xml

# 2) 掃目錄、抽傷寒相關書（shl 的腳本）
cd D:\2026\shl
bun run src/scan-jc.ts --extract

# 3) 只掃目錄、不抽書
bun run src/scan-jc.ts
```

產出：

| 檔案 | 內容 |
|---|---|

| `data/jc-sources.tsv` | 146 本傷寒／金匱／脈經／千金翼／外臺／聖惠相關書；`in_witnesses` 標記是否已在清單 |
