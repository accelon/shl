# 別本異文表 pilot（`variants.tsv`）

> 2026-11-05。`src/build-variants.ts`；資料 `data/variants.tsv`。
> 目的：證明軌號對齊後，可以直接做版本校勘，不必再換算座標。

## 1. 方法

- 取 `xref.tsv` 中 KP／GL／YH 的 **1:1、A/B 級**列。
- 兩端文字先過 `normHan`：只留漢字，統一常見異體（說／説、為／爲、脈／脉、太／大、薑／姜、痙／痓、鞕／硬、濇／澀、欬／咳、胷／胸、讝／譫…）。
- 對正規化後的字串做字級 LCS，抽出替換／增刪的 hunk；只留長度 ≤4 的差異，避免整條改寫。
- 每列給 4 字上下文，方便回看原句。

## 2. 輸出

`data/variants.tsv`：

| 欄 | 說明 |
|---|---|
| `witness` | KP／GL／YH |
| `clause` | 宋本條號 |
| `sb_context` / `witness_context` | 宋本／別本的上下文（正規化後） |
| `sb_diff` / `wt_diff` | 差異片段 |
| `confidence` | 沿用 xref |

目前 543 列：KP 125、GL 157、YH 261。

```text
GL  ...
YH  ...
```

## 3. 限制

- **不是完整校勘**：只做 1:1 的條；`1:n`（注文夾在中間）與 `n:1`（合併條）未做。
- **只比字，不比標點**：句讀差異（。／，）已去掉；若要句讀異文，另建表。
- **正規化會吃掉一部分異文**：`normHan` 統一的異體（如太／大）不會出現在表裡；那些是「字形差異」，不是「用字差異」。
- **沒有判斷對錯**：表只列差異，不定是非；要校勘立場時另寫 `note`。
- **早期傳本未收**：脈經、千金翼、外臺、聖惠方是節錄／類編，1:1 對位少，之後再補。
