## 3. 怎麼用

- **不要拿四庫本當 base**：四庫本沒有宋本 398 條號，且經過館臣改字；只作**對校本**。
- 傷寒微旨論已放進 `witnesses.tsv`（WZ，status `downloaded`），是目前唯一全文。
- 其餘四庫本先登記在 `skqs-med.tsv`，要收時再逐本抽；不要一次全收，避免右欄爆量。
- 四庫本可補 jicheng 缺書，但不建議取代 jicheng 的通行排印本。

## 4. 限制

- skqs 的 XML 是「卷」級，沒有 `書名`／`章節` 標籤；要靠 `<卷>子部,醫家類,書名,卷N</卷>` 切。
- 四庫本有避諱、改字、刪改；校勘時要與通行本並看。
- 這次只抽了傷寒微旨論；其他書要另寫 extractor（或先把卷切出來再解析）。
